## 📋 Описание

Графическое приложение на Python с использованием Tkinter для расчёта времени закипания воды в чайнике. Программа учитывает множество физических параметров: объём воды, мощность чайника, начальную температуру, высоту над уровнем моря, массу и материал корпуса.

## ✨ Возможности

- 🎯 **Точный расчёт** на основе физических формул (Q = m·c·ΔT)
- 🌍 **Учёт высоты над уровнем моря** — корректировка точки кипения
- 🧪 **Различные материалы корпуса** — сталь, стекло, керамика, пластик
- ⏱️ **Встроенный таймер** обратного отсчёта с оповещением
-  **Две темы оформления** — светлая и тёмная
- 🎚️ **Удобные ползунки** для ввода параметров (без ошибок ввода)
- 📊 **Расчёт энергопотребления** в кВт·ч
